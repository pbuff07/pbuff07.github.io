最近使用 VSCode Remote SSH 连接远程主机时，卡在 `Downloading VS Code Server` 阶段，表现为一直下载或反复要求重新连接。

参考链接：

- [Remote-SSH stuck on "Downloading VS Code Server" #11040](https://github.com/microsoft/vscode-remote-release/issues/11040)

这类问题可通过调整两处 Remote SSH 设置来修复：

1. `Remote.SSH: Use Exec Server` **不勾选**
2. `Remote.SSH: Permit Pty Allocation` **勾选**

设置界面示意图如下：

![Remote.SSH Use Exec Server 不勾选](https://pbuff-blogs-1257793641.cos.ap-chengdu.myqcloud.com//blogs20260508104725.png)

![Remote.SSH Permit Pty Allocation 勾选](https://pbuff-blogs-1257793641.cos.ap-chengdu.myqcloud.com//blogs20260508104800.png)

修改后重新连接远程主机，通常即可恢复正常。
